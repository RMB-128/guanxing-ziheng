## 项目简介

观形智衡是一套融合计算机视觉、中医辨证与多智能体协同决策的**居家式体态健康自评系统**。用户仅需上传正面/侧面体态图像与舌苔图像，系统即可自动完成：
- ✅ 26关节点人体姿态估计（MMPose）
- ✅ 高精度人体轮廓分割（SAM ViT-H，IoU > 0.98）
- ✅ 11项体态/体型指标量化分析
- ✅ 中医体质辨识与舌象自动分析
- ✅ 五智能体协同生成的个性化健康评估报告
- ✅ 历史趋势复查与长期健康跟踪

## 视觉算法管线

| 阶段 | 方法 | 性能指标 |
|------|------|---------|
| 人体关键点检测 | MMPose (HRNet + body26) | 横向误差 < 8‰ 肩宽<br>纵向误差 < 3‰ 身高 |
| 人体区域分割 | SAM ViT-H + 关键点Prompt | 平均 IoU > 0.98 |
| 几何校正 | PCA 主轴估计 + 仿射变换 | 指标波动 < 2% |
| 体态指标 (4项) | 头前伸/高低肩/骨盆倾斜/膝对齐 | ETR < 8.5% |
| 体型指标 (7项) | 头身比/腿身比/大小腿比等 | 全部无量纲标准化 |

## 多智能体协同架构

```
        ┌──────────────┐   ┌──────────────┐
        │ 体态分析智能体 │   │ 中医分析智能体 │
        └──────┬───────┘   └──────┬───────┘
               │                  │
               └────────┬─────────┘
                        │
               ┌────────┴────────┐
               │  综合分析智能体   │
               └────────┬────────┘
                        │
          ┌─────────────┴─────────────┐
          │                           │
   ┌──────┴──────┐            ┌──────┴──────┐
   │  复查智能体   │            │  统筹智能体   │
   │ (趋势分析)   │            │ (专家模式)   │
   └─────────────┘            └─────────────┘
```

**两种分析模式：**
- **常规模式**：线性流转，快速生成基础评估报告
- **专家深度模式**：统筹智能体质控 → 迭代优化 → 精细解读

## 快速开始

### 前端
```bash
cd WebFrontEnd
npm install
npm run dev
```

### 后端
```bash
conda create -n guanxing python=3.10
conda activate guanxing
pip install -r requirements.txt

# 安装 MMPose (按官方指引)
# 安装 SAM (按官方指引)
# 下载 SAM-ViT-H 权重至 models/ 目录

uvicorn main:app --host 0.0.0.0 --port 8000
```
