# 大学生创新创业训练计划项目申报书

## 项目名称

**基于多模态视觉分析的中西医融合体态评估系统——"观形智衡"的临床验证与算法优化**

## 项目类型

创新训练项目（建议申报国家级）

---

## 一、立项背景与研究意义

近年来我国居民超重与肥胖率持续攀升，已成为慢性病防控工作的关键风险因素。国家《"健康中国2030"规划纲要》将全民健康与科学体重管理提升至战略高度。然而，现有体态管理工具存在三大困境：（1）自评工具匮乏，公众无法便捷获取客观体态评估；（2）分析维度单一，多局限于BMI等浅层指标，缺乏中西医融合的多维评估能力；（3）专业检测流程繁琐，难以支撑日常化高频次复查。

本项目"观形智衡"在前期已完成的省一等奖作品基础上，围绕以下核心目标开展进一步研究：

1. **扩大临床验证样本量**：从现有5人扩展至50人以上，建立统计显著性检验
2. **视觉算法优化**：引入3D姿态估计，从2D关键点进化到3D骨架重建
3. **中医体质辨识精细化**：构建更完整的舌象-体质映射知识库
4. **多智能体协同效率优化**：引入并发机制，降低系统响应延迟

## 二、前期研究基础

本项目已具备坚实的前期基础：

### 2.1 已实现系统
- **视觉算法管线**：MMPose（body26关键点）+ SAM（ViT-H人体分割）+ PCA校正，关键点检测误差<8‰肩宽、SAM分割IoU>0.98
- **指标体系**：4项体态指标 + 7项体型比例指标，完整数学定义与精度验证
- **多智能体架构**：体态分析、中医分析、综合分析、复查分析、统筹评估五智能体协同
- **Web应用**：Vue3 + FastAPI + SQLite，已部署可访问

### 2.2 验证成果
- 2026年全国大学生计算机设计大赛湖北省一等奖
- 华中科技大学同济医学院附属协和医院临床营养科5人初步验证：核心判定结论与医师诊断高度一致
- 11项体态/体型指标的误差阈值比（ETR）均不超过8.5%

### 2.3 现有技术瓶颈
- 样本量不足（5人），制约统计学显著性检验
- 2D姿态估计受视角限制，部分指标（如骨盆旋转）无法可靠测量
- 中医问诊模块依赖固定问卷，缺乏自适应追问能力

## 三、研究内容

### 3.1 临床验证扩展与统计分析
- **目标样本量**：50-80名受试者（含超重/肥胖组与正常对照组）
- **对照方法**：协和医院临床营养科医师同时出具独立诊断 → 双盲对照 → 逐项比对
- **统计方法**：
  - 配对t检验（连续变量：BMI、腰围等）
  - Cohen's Kappa（分类变量：肥胖类型、舌象特征）
  - Bland-Altman分析（体态指标一致性评估）
  - ROC曲线（体态异常问题筛检效能）

### 3.2 3D姿态估计集成
- 从2D body26关键点 → 引入VideoPose3D或MotionBERT做2D-to-3D提升
- 新增可靠指标：骨盆旋转角度、脊柱侧弯指数、膝关节内外翻角
- 与现有2D指标做一致性验证

### 3.3 中医体质辨识精细化
- 扩充舌象图像样本库（目标：200+例标注）
- 引入轻量级ViT做舌象自动分类（淡红舌、红舌、紫暗舌、齿痕舌等）
- 构建"十问→体质"映射知识图谱，支持缺省值的自适应推理

### 3.4 多智能体协同效率优化
- 引入Agent并发调度：体态分析智能体与中医分析智能体并行执行
- 设计智能体间的信息共享协议，减少重复推理
- 目标：综合报告生成时间降低50%以上

## 四、技术路线

```
Phase 1 (第1-2月): 临床数据采集 + 3D姿态估计模型调研与选型
Phase 2 (第3-5月): 统计分析 + 3D姿态集成开发 + 舌象样本标注
Phase 3 (第6-8月): 论文撰写 + 智能体并发优化 + 系统集成测试
Phase 4 (第9-10月): 消融实验 + 论文投稿 + 结题报告
```

## 五、创新点

1. **计算机视觉×中医辨证的量化交叉**：首次将3D人体姿态估计与舌象自动分类统一在同一评估框架中
2. **临床可解释性验证**：与三甲医院双盲对照，所有输出指标均有明确的临床判定阈值和ETR量化
3. **轻量化部署**：基于FastAPI+SQLite的本地部署架构，无需GPU服务器即可运行核心推理
