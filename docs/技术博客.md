# 从姿态估计到健康评估：MMPose + SAM 联合驱动的体态分析系统设计与实现

## 1. 问题背景

近年来，随着《"健康中国2030"规划纲要》的推进，科学体重管理与体态评估已被提升至国家战略高度。然而，当前公众健康管理实践中，体态评估手段仍存在明显不足：自评工具匮乏、分析视角单一（多局限于BMI等浅层指标）、专业检测流程繁琐且难以高频次复查。

针对以上痛点，我们设计并实现了一套名为**"观形智衡"**的智能体态管理系统。该系统仅需用户上传正面和侧面两张体态图像，即可自动完成人体关键点检测、轮廓分割、倾斜校正与11项体态/体型指标的量化计算，并与中医问诊数据融合，最终由多智能体协同架构生成个性化健康评估报告。本文重点介绍系统的**视觉算法管线**设计与实现。

---

## 2. 算法总体架构

系统的视觉处理管线分为四个阶段：

1. **基于 MMPose 的人体关键点检测** — 提取人体26个关键关节坐标
2. **基于关键点提示的 SAM 人体分割** — 精确提取人体轮廓掩码
3. **基于 PCA 的主轴估计与倾斜校正** — 消除拍摄角度偏差
4. **体态与体型比例指标计算** — 量化11项健康评估指标

```mermaid
graph LR
    A[输入正/侧面图像] --> B[MMPose 关键点检测]
    B --> C[高置信度关键点筛选]
    C --> D[关键点作为 Prompt 提示 SAM]
    D --> E[SAM 人体区域分割]
    E --> F[PCA 主轴估计与倾斜校正]
    F --> G[11项体态体型指标计算]
    G --> H[输出结构化体态报告]
```

## 3. 关键点检测：为什么选择 MMPose？

人体关键点检测是整个管线的基石。我们对比了三种主流方案：

| 方案 | 关键点数 | 推理速度 | 精度 | 可扩展性 |
|------|:---:|:---:|:---:|:---:|
| MediaPipe Pose | 33 | 极快 | 中 | 低 |
| OpenPose | 25/135 | 慢 | 高 | 中 |
| **MMPose (HRNet)** | **26 (body26)** | **快** | **极高** | **高** |

我们最终选择 MMPose 的核心考量在于其**模块化架构**：

- **数据模块**：内建数据增强管线（随机翻转、仿射变换、多尺度训练），显著提升模型对不同体型、遮挡场景的泛化能力
- **骨干网络**：选用 HRNet，通过高分辨率特征保持机制避免传统下采样→上采样架构的信息损失，对遮挡关节和小目标关节的定位更精确
- **预测头**：热力图预测头输出关键点概率分布，通过峰值解码得到亚像素级坐标，配合 OKS Loss 优化定位精度

我们采用 **body26 关键点配置方案**（鼻尖、左右眼、左右耳、左右肩、左右肘、左右腕、头部、颈部、左右髋、左右膝、左右踝等），相比标准的17点方案，新增了头面部和足部关键节点，对头前伸、骨盆倾斜、膝对齐等体态异常指标的表征能力显著提升。

推理器初始化关键代码逻辑：

```python
from mmpose.apis import MMPoseInferencer

# 加载 body26 预训练模型
inferencer = MMPoseInferencer(
    pose2d='rtmpose-m_8xb256-420e_body26-256x192',
    device='cuda'
)

# 端到端推理：检测器定位人体 + 姿态估计网络回归关键点
results = inferencer(image_path)
keypoints = results['predictions'][0][0]['keypoints']  # (26, 2)
scores = results['predictions'][0][0]['keypoint_scores']  # (26,)
```

### 精度验证

在含人工标注真值的测试数据集上，我们对每帧图像计算归一化绝对误差（横向误差/肩宽、纵向误差/身高）。结果如下：

- **横向平均归一化误差**：0.0076（不足肩宽的 8‰）
- **纵向平均归一化误差**：0.0021（不足身高的 3‰）
- **横向最大归一化误差**：0.0164
- **纵向最大归一化误差**：0.0046

关键点在头面部、躯干主干、四肢及踝足部位均与人工标注高度重合，仅在个别关节处存在轻微可辨偏移。

## 4. 人体分割：关键点驱动的 SAM Prompt 策略

### 为什么需要人体分割？

关键点检测给出的是离散的关节坐标，而体态指标计算（如上下身面积比、腹部前突指数、头身比等）需要完整的人体轮廓信息。因此我们需要一个能够高精度分割人体区域的方法。

### 方法选择

传统分割方案（如 U-Net 或 DeepLab 系列）需要针对特定场景标注大量数据并微调模型。我们选择 Meta 的 **Segment Anything Model (SAM)** 的核心理由在于其**零样本泛化能力**——无需在人体分割数据集上额外训练，仅靠提示驱动即可完成任意目标的高精度分割。

SAM 的三大核心模块在人体分割场景中的作用：

| 模块 | 架构 | 本系统中的角色 |
|------|------|---------------|
| 图像编码器 | ViT-H | 提取全局视觉特征，一次编码、多次复用 |
| 提示编码器 | 位置嵌入 | 将 MMPose 关键点坐标编码为前景提示 |
| 掩码解码器 | Transformer Decoder | 融合图像特征与提示特征，输出多候选分割掩码及 IoU 置信度 |

### 关键创新：基于置信度筛选的关键点 Prompt 策略

直接将 MMPose 的全部26个关键点作为 SAM 的点提示输入存在风险：低置信度关键点（被遮挡或定位不准的关节点）会向 SAM 传递错误的提示信息，导致分割区域偏移。

我们的策略：

1. **设定置信度阈值**（实验中设为0.3），仅保留高置信度关键点
2. **全部标记为前景点**（不留背景点）：因为人体区域是连续的，多点前景提示足以引导 SAM 锁定目标
3. **启用多掩码输出模式**：单次推理生成多组互补掩码，按 IoU 置信度自动选取最优结果

```python
def build_sam_prompts(keypoints, scores, threshold=0.3):
    """将高置信度关键点构造为 SAM 点提示"""
    valid_mask = scores > threshold
    point_coords = keypoints[valid_mask]  # (N, 2)
    point_labels = np.ones(len(point_coords))  # 全部标记为前景
    return point_coords, point_labels
```

### 分割精度

以人工精标注的像素级真值掩码为基准，评估指标采用交并比（IoU）。实验结果：**平均 IoU > 0.98**。预测掩码与真值在人体主体轮廓、四肢边界等关键部位高度一致，仅在细长结构（如手指、耳廓）和边缘过渡区域存在轻微偏差。

## 5. 几何校正：PCA 主轴估计与倾斜校正

单目图像存在天然的视角与投影不确定性。用户拍摄时设备的微小倾斜、人体的自然站姿偏移都会影响体态指标的精确计算。我们采用基于 PCA 的视角标准化策略：

### 主轴估计

基于 SAM 分割结果，提取人体掩码的前景像素集合 $\{(x_i, y_i)\}_{i=1}^{N}$，通过主成分分析（PCA）计算像素分布的协方差矩阵的第一主成分方向，即人体的"中轴线"。中轴线与图像垂直轴的夹角 $\theta$ 反映整体姿态倾斜程度。

### 同步变换

使用计算得到的夹角 $\theta$ 进行全局校正：

- **RGB 图像**：双线性插值仿射旋转变换
- **二值掩码**：最近邻插值旋转（保持类别边界清晰）
- **关键点坐标**：同一仿射变换矩阵同步变换

三者共享同一变换矩阵，确保校正后图像、掩码、关键点在规范化坐标系下严格配准。

```python
import cv2
import numpy as np
from sklearn.decomposition import PCA

# 1. 基于掩码前景像素的 PCA
foreground_pts = np.argwhere(mask > 0)[:, ::-1]  # (N, 2) - (x, y)
pca = PCA(n_components=2).fit(foreground_pts)
principal_axis = pca.components_[0]  # 第一主成分
angle = np.arctan2(principal_axis[1], principal_axis[0]) * 180 / np.pi

# 2. 构建旋转矩阵并同步变换
center = (image.shape[1] // 2, image.shape[0] // 2)
M = cv2.getRotationMatrix2D(center, angle - 90, 1.0)

corrected_image = cv2.warpAffine(image, M, image.shape[:2][::-1],
                                  flags=cv2.INTER_LINEAR)
corrected_mask = cv2.warpAffine(mask, M, mask.shape[:2][::-1],
                                 flags=cv2.INTER_NEAREST)
```

## 6. 体态指标计算：从像素到临床意义

在完成关键点提取、人体分割与倾斜校正后，基于 body26 关键点坐标与人体掩码轮廓，我们定义了**4项体态指标**与**7项体型比例指标**。所有指标均采用无量纲比值形式，消除像素尺度和拍摄距离的系统误差。

### 体态异常指标（4项）

| 指标 | 视角 | 核心公式 | 临床意义 |
|------|:---:|------|------|
| 头前伸指数 | 侧面 | $\frac{\|x_{ear} - x_{shoulder}\|}{y_{hip} - y_{shoulder}}$ | 数值越大，头部前伸越明显（常见于长期低头族） |
| 高低肩指数 | 正面 | $\frac{y_{right\_shoulder} - y_{left\_shoulder}}{x_{right\_shoulder} - x_{left\_shoulder}}$ | 正值=左肩偏高，绝对值越大高低肩越严重 |
| 骨盆倾斜指数 | 正面 | $\frac{y_{right\_hip} - y_{left\_hip}}{x_{right\_hip} - x_{left\_hip}}$ | 正值=左髋偏高，反映骨盆侧倾程度 |
| 膝对齐指数 | 侧面 | $\frac{d(knee, line(hip, ankle))}{len(hip, ankle)}$ | 数值越大，膝关节偏离正常力线越严重 |

### 体型比例指标（7项）

头身比、腿身比、大小腿比、躯干身高比、上下身面积比、头肩比、腹部前突指数。

每一项指标均有明确的数学定义和物理意义。例如，**上下身面积比**以髋线为界，通过掩码像素统计计算上下身体量分布：

$$I = \frac{S_{upper}}{S_{lower}}$$

- I > 1：上身比重较大，重心偏上
- I < 1：下身比重较大，重心偏下

### 误差阈值分析

为量化指标计算误差对临床判定的干扰程度，定义**误差阈值比（Error-to-Threshold Ratio）**：

$$ETR_m = \frac{\varepsilon_m}{T_m}$$

其中 $\varepsilon_m$ 为指标计算误差，$T_m$ 为该指标的改善/加重判定阈值。实验结果表明，四项核心体态指标的 ETR 均不超过 8.5%——即计算误差远不足以导致体态问题误判。

## 8. 总结与工程思考

本项目从需求分析到临床验证，完整走通了一条"计算机视觉 + 中医辨证 + 多智能体决策"的技术路线。以下是几点工程思考：

1. **MMPose + SAM 的组合在特定领域的姿态分析任务中优势明显**：MMPose 提供高精度结构信息作为 SAM 的先验引导，SAM 将离散关键点扩展为连续轮廓，两者形成互补。相比纯端到端的姿态估计方案，这种模块化管线可解释性更强，每个中间环节均可独立调试和验证。

2. **PCA 校正环节不可省略**：在原型阶段，我们曾跳过倾斜校正直接计算指标，发现同一受试者的不同拍摄角度导致指标波动超 12%。引入 PCA 校正后波动降至 2%以内——对于临床场景，这一步骤不是可选优化，而是必要前提。

3. **多候选掩码输出的价值被低估**：SAM 的 `multimask_output=True` 模式在小样本场景下是极其实用的"安全网"——即便单一提示存在歧义，多候选机制也能通过 IoU 评分自动筛选最优结果。
