## 论文选题方向

### 方向A（推荐首选）：临床交叉验证方向
**题目示例**：《基于计算机视觉的体态评估系统与三甲医院诊断的一致性研究——以"观形智衡"为例》

**论文结构：**
1. **引言**：居家体态评估的临床需求 + 现有工具的不足
2. **系统简述**：视觉算法管线（简化版，200字）+ 多智能体架构（100字）
3. **方法**：
   - 受试者招募标准与排除条件
   - 数据采集流程（正侧位照片 + 舌苔 + 十问）
   - 视觉指标计算方法（可引用原作品文档）
   - 统计分析方法（配对t检验、Kappa、Bland-Altman、ROC）
4. **结果**：
   - 受试者基线特征表
   - 系统 vs 医师诊断逐项对比表（如原文档表4.3-1和4.3-2的格式）
   - Bland-Altman图（各体态指标）
   - ROC曲线（肥胖分类的灵敏度和特异度）
5. **讨论**：
   - 与现有自评工具的对比优势
   - 偏差来源分析（拍摄角度残留误差、样本量限制）
   - 临床适用场景：居家筛查 vs 辅助诊断
6. **结论**

**优势：** 有协和医院背书，数据可靠性高；医学期刊对"算法验证"类论文接受度好；统计方法标准化，审稿人容易判断质量。

**数据需求：** 当前5人数据可用于"初步研究"（pilot study）投稿，但建议大创期间扩展到30+人后投"正式研究"。

### 方向B：技术方法方向
**题目示例**：《MMPose与SAM联合驱动的体态分析：关键点引导分割与多指标量化方法》

**论文结构：**
1. **引言**：姿态估计与分割在健康评估中的角色
2. **相关工作**：OpenPose、MediaPipe、传统阈值分割的局限
3. **方法**（重点）：
   - body26关键点配置的优势分析
   - 置信度筛选的Prompt策略
   - PCA校正的必要性证明（消融实验）
   - 11项指标的数学模型
4. **实验**：
   - 关键点精度（原文档4.2.1节）
   - 分割IoU（原文档4.2.3节）
   - 指标ETR分析（原文档4.2.2节）
   - 消融实验：无PCA校正 vs 有PCA校正的指标波动对比
5. **讨论**
6. **结论**

**优势：** 数据齐全（原文档已有大量实验数据），技术路线清晰；适合投《计算机应用与软件》。

**建议：** 如果万一老师的遥感方向能提供某种方法上的交叉启发（比如遥感中的几何校正方法），可在"讨论"中加入一笔。

### 方向C：最短路径——原文档直接改写为会议论文
**目标会议**：2027年中国遥感大会（智能遥感与健康应用分会场）或中国生物医学工程大会

只需将原文档的3.2节（视觉算法）+ 3.3节（多智能体）+ 4.2-4.4节（测试）整理为6-8页标准会议论文格式，补充英文摘要和关键词。一周内可完成初稿。
